## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- No installation required!

### Usage

1. Clone the repository:
```bash
git clone https://github.com/Subhasri2505/Portfolio.git
```

2. Open the HTML file in your browser:
```bash
cd Portfolio
open subhasri_portfolio.html
```

Or simply double-click the `subhasri_portfolio.html` file.

## 🎨 Customization

You can easily customize the portfolio by editing the CSS variables in the `<style>` section:

```css
:root {
  --navy: #0a0f2c;
  --blue: #2563eb;
  --cyan: #06b6d4;
  /* ... more colors ... */
}
```
